# Learning sources and attribution

The runnable code in this starter repository is original demonstration code created for the learner's study portfolio, not copied from a Udemy course. If you reuse code/assets from an instructor, check the license and add the course name, author, and link in the relevant project README.

See `docs/COURSE-SECTIONS.md` for direct links to all 10 courses.

Do **not** present tutorial exercise files as solely your own engineering design. Document your improvements, tests, troubleshooting, architecture decisions and feature additions.
