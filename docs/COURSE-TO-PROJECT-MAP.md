# Course-to-project crosswalk

No Udemy course is excluded. One course/day prevents context switching; project files can **evolve across multiple days** as later course techniques strengthen previous work.

| Order | Days | Course | Main proof | Target after timebox |
|---|---|---|---|---|
| 1 | 1–2 | [C1 — KodeKloud Beginner](https://www.udemy.com/course/learn-docker/) | CLI lab + first Compose deployment | Docker-only core + labs **target completion** |
| 2 | 3 | [C2 — Ricardo](https://www.udemy.com/course/docker-from-zero-to-hero/) | Dockerfile optimization + volume persistence | Selected sections |
| 3 | 4 | [C3 — Jason Cannon](https://www.udemy.com/course/docker-tutorial/) | 3 reproducible incidents + network/volume proof | Selected sections |
| 4 | 5 | [C7 — Bret Fisher](https://www.udemy.com/course/docker-mastery/) | Improved image layers + Compose assignment | Docker-only sections |
| 5 | 6–7 | [C10 — Fast-Track](https://www.udemy.com/course/fast-track-docker/) | Full-stack flagship + smoke CI | Functional MVP, **not** necessarily course complete |
| 6 | 8 | [C4 — Zero to Cloud](https://www.udemy.com/course/docker-training-learn-docker-from-zero-to-cloud/) | Five-language packaging | Selected project |
| 7 | 9 | [C5 — Oleksandr](https://www.udemy.com/course/docker-and-docker-compose-project-deployment-from-scratch/) | Auth/API/MongoDB course-inspired extension | Design + starter; stretch to runnable demo |
| 8 | 10 | [C6 — Luke Robertson](https://www.udemy.com/course/docker-containers-from-fundamentals-to-production/) | Resource/security/registry evidence | Selected labs |

| 10 | 12–14 | [C9 — Zeal Vora DCA](https://www.udemy.com/course/docker-certified-associate/) | Domain checklist, mock results, knowledge-gap report | Selected Docker domains, **partial DCA** |

> A course only counts as **completed** when you actually finish the defined lessons/labs. All 10 are *covered*, not 10 finished. Course inspirations must be credited. See [ATTRIBUTION.md](ATTRIBUTION.md).
